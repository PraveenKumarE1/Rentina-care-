# Model assets

Place validated `.mat` or supported network assets here:

- `resnet50_dr.mat`
- `inception_dr.mat`
- `densenet_dr.mat`
- `vit_dr.mat`
- `vessel_unet.mat`

The repository ships a transparent classical baseline. These files are intentionally not fabricated: clinical deployment requires weights trained and validated on approved datasets, calibration data, and an ophthalmologist-reviewed operating point.
