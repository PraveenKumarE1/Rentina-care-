# User manual

Run `startup`, then `result = main_pipeline(image)`. Review `result.quality.feedback` before interpreting the grade. Use `report_generator` for an HTML/PDF report and `db_manager` for SQLite persistence. The `referable` flag means level 2 or higher in the International Clinical Scale.

This development baseline is not approved for clinical decisions. A qualified ophthalmologist must review outputs, especially ungradable images and any result generated before validated model assets are installed.
